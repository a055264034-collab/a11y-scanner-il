# בודק נגישות לאתרים — ת״י 5568

כלי ווב (עברית, RTL) שמקבל כתובת אתר, סורק את הדפים הפומביים באותו דומיין ומפיק דוח נגישות מול התקן הישראלי **ת״י 5568 חלק 1** (מהדורת ספטמבר 2023), המאמץ את **WCAG 2.0 רמה AA** עם תוספות לאומיות.

## מה הכלי עושה

- סריקת דפים (crawl) באותו דומיין, עד 50 דפים, בדפדפן אמיתי (Chromium headless).
- בדיקה אוטומטית עם מנוע axe-core מול תגיות WCAG 2.0/2.1/2.2 ו-best-practice.
- דוח בעברית: סיכום כולל, ממצאים לפי דף וכלל, חומרה (קריטי/חמור/בינוני/קל), מיפוי לקריטריוני WCAG, והמלצת תיקון לכל כלל.
- חלוקה בין "נדרש לפי החוק" (WCAG 2.0 A/AA) לבין "מעבר לדרישה" ו"פרקטיקה מומלצת".
- היוריסטיקה לזיהוי קישור להצהרת נגישות.
- רשימת הבדיקות הידניות הנדרשות (קורא מסך, מקלדת, הצהרת נגישות, מסמכים ועוד).

## מה הכלי לא עושה (בכוונה, וכתוב בדוח)

בדיקה אוטומטית מכסה רק חלק מהדרישות. תוצאה נקייה אינה ערובה לעמידה מלאה בחוק, והדוח אינו ייעוץ משפטי.

## הרצה מקומית

```bash
npm install
PUPPETEER_EXECUTABLE_PATH=/usr/bin/chromium npm start
# http://localhost:3000
```

## פריסה (Render)

Dockerfile כולל Chromium. משתנה סביבה: `PORT` (Render מזריק אוטומטית).

## אבטחה

- נתמכות רק כתובות http/https ציבוריות; כתובות פנימיות (localhost, רשתות פרטיות) חסומות.
- מגבלת דפים לסריקה ומגבלת סריקות במקביל.
- `/demo/inaccessible` — דף דמו לא נגיש בכוונה לצורך הדגמה.
